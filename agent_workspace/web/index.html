THE WORKFLOW BEHIND THE WORKSPACE

Four stages. One persisted case.

  1. Read & ground. A local model extracts invoice fields from actual PDF text. Every value must be supported by an exact source quote.
  2. Investigate with tools. The model chooses read-only tools for orders, receiving, vendor master, payment history, and policy. Tool inputs and outputs appear in the execution trace.
  3. Challenge the result. Exact financial controls are recomputed independently. Missing tool checks return to investigation. Unsupported memo citations or a conflicting recommendation trigger revision.
  4. Pause & resume. LangGraph checkpoints the case before human review. New receiving evidence resumes the same case, reruns the investigation, and preserves the earlier decision history.
The framework orchestrates the workflow; it does not certify evidence. Bank details are compared by account suffix only. Source authenticity, user authentication, OCR, accounting integrations, and production approval controls are outside this prototype. Policy and system records are synthetic.

No hidden chain-of-thought is displayed. The activity view contains task descriptions, tool calls, computed checks, and explicit reviewer decisions.
