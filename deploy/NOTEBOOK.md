# Standalone notebook

The final notebook is `submission/Month_end_review.ipynb`, also available at `notebooks/Month_end_review.ipynb`. Open in Python 3.10+ Jupyter and Run All. It embeds its data and standard-library implementation, requires no package installation or tunnel, and includes actual executed outputs.

For an interactive demo, open `submission/OPEN_THIS.html` directly in a desktop browser. The same file is the public Pages homepage. See the root README for the complete workflow.
